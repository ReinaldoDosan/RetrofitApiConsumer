<h1>Retrofit API Consumer</h1>

<p>
  Android application developed in Kotlin to demonstrate REST API consumption using Retrofit.
</p>

<h2>Technologies</h2>
<ul>
  <li>Kotlin</li>
  <li>Retrofit</li>
  <li>Coroutines</li>
  <li>Android SDK</li>
</ul>

<h2>Features</h2>
<ul>
  <li>REST API consumption</li>
  <li>HTTP GET requests</li>
  <li>API response handling</li>
  <li>Data display on screen</li>
</ul>

<h2>Objective</h2>
<p>
  To practice API integration in Android applications and build an Android development portfolio.
</p>
